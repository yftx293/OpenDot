# Real-model MCP approval pilot

On source `a29a21a`, an isolated authenticated Node Durable product Session
used the authorized Magpie `opencode-go-3/beam-free` model with a local stdio
MCP echo fixture. The synthetic model endpoint received no requests. The actual
model proposed the declared tool with the exact random argument; its effect
ledger contained no call before approval. An owner-approved exact-argument
request produced one execution, a completed input and a single assistant reply
containing the echoed value. The report stores only outcome booleans/counts,
not the fixture token, provider credentials or conversation text.

This is one real-model Node/API pilot with a synthetic local MCP server. It is
not a real Kimi WebBridge, paired-device, Chrome UI, denial, restart, Cloud or
multi-turn acceptance. Existing synthetic-model tests cover some of those
separately; they do not establish real-model reliability.
