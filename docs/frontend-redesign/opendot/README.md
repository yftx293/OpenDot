# OpenDot visual evidence

Built Web UI against disposable authenticated HTTP/SQLite fixtures, with actual
Goal/Group/approval/device APIs. Model responses are fixtures. Mobile, keyboard
and touch use Chromium emulation; these images are not physical-device or cloud
deployment acceptance. App logo is static; Dot names/avatars remain individual.
The legacy fixture Dot named `Miniclaw` is deliberately preserved, while the
`opendot` conversation captures show a real settings rename to `小点`.

Desktop viewport 1440×900; mobile 390×844. Animations are disabled only during
capture. Some device permission images use the same emulated product workflow.
